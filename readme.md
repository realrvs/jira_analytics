# 📊 Jira Analytics Tool с AI-аналитикой

Инструмент для анализа данных из Jira с использованием YandexGPT для генерации рекомендаций по улучшению процессов разработки.

## 🚀 Возможности

- 📡 **Подключение к Jira API** — получение данных о задачах и спринтах
- 📊 **Расчет ключевых метрик**:
  - Процент завершения задач
  - Скорость команды (Velocity)
  - Загрузка исполнителей
  - Распределение по статусам и приоритетам
  - Story Points по спринтам
- 🤖 **AI-аналитика через YandexGPT**:
  - Оценка общей эффективности проекта
  - Анализ загрузки команды
  - Рекомендации по улучшению процессов
  - Детектирование проблем и блокеров
- 📈 **Визуализация данных**:
  - Интерактивные дашборды (Plotly)
  - Отдельная страница с AI-рекомендациями
  - Экспорт в HTML и PNG

## 📋 Требования

- Python 3.8+
- Доступ к Jira (Cloud или Server)
- API токен Jira
- (Опционально) Yandex Cloud API ключ для AI-аналитики
