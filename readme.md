## 📌 О проекте

**Jira Analytics Tool** — это AI-платформа для управления проектами, которая помогает руководителям и командам:

- 📊 **Отслеживать метрики** проекта в реальном времени
- 🤖 **Получать AI-рекомендации** для улучшения процессов
- 📧 **Автоматически отправлять отчеты** руководству
- 🚨 **Выявлять блокеры** до того, как они станут проблемой

---

## 🚀 Основные возможности

### 1. Executive Summary (Дайджест для руководства)

| Функция | Описание |
|---------|----------|
| **Общий статус** | Total Issues, Completion Rate, Blocked, Efficiency |
| **Риски** | Автоматическое выявление HIGH/MEDIUM рисков |
| **Рекомендации** | AI-рекомендации от YandexGPT |
| **PDF отчет** | Профессиональный PDF с данными |
| **Email рассылка** | Автоматическая отправка отчетов |

### 2. Метрики и аналитика

| Метрика | Описание |
|---------|----------|
| **Velocity** | Скорость команды (Story Points/спринт) |
| **Completion Rate** | Процент завершенных задач |
| **Blocked** | Количество заблокированных задач |
| **Efficiency** | Эффективность процесса (HIGH/MEDIUM/LOW) |
| **WIP** | Задачи в работе |

### 3. AI-рекомендации

- Интеграция с **YandexGPT**
- Генерация рекомендаций на основе метрик
- Приоритизация (HIGH/MEDIUM/LOW)
- Применение и оценка рекомендаций

### 4. Интеграция с Jira

- Получение списка проектов
- Синхронизация задач
- Обновление статусов
- Webhook поддержка

   I[Loki] --> J[Grafana]
    K[Prometheus] --> J
